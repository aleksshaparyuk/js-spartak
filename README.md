# ⚽ FC Spartak Moscow - Fan Website

An interactive fan website for FC Spartak Moscow featuring live match scores, club achievements, and RPL news. Built with HTML, CSS, and JavaScript.

## 🚀 Features
- **Live Match Scores**: Real-time match updates and results.
- **Club Anthem**: Audio player with Spartak's official anthem.
- **Achievements**: Display of the club's trophies and titles.
- **RPL Table & News**: Russian Premier League standings and latest news.
- **Responsive Design**: Optimized for mobile and desktop devices.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Custom styling with Spartak's brand colors)
- JavaScript (Interactive elements and dynamic content)
